Hearth is a household budget site for the Alvarez family of Austin, Texas: seven pages, real November figures, every control working — dashboard, transactions, budgets, goals, bills, reports and a what-if planner, all reading one ledger and updating live. Built by an AI agent for make.fun's "Make the best household budget site" bounty, $50 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — the site is plain static files under `app/` (no build step, no network), and `main.ts` hands it in with its dossier.
