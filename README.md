Hearth — the Alvarez family's household budget site. Seven working pages (dashboard, transactions, budgets, goals, bills, reports, paycheck planner) over real November 2026 figures: $7,240 income, $4,505 spent, $1,200 auto-saved, every control live — add a transaction and the dashboard, budgets and reports update at once. Static files, no network, no framework; runs on desktop and phone.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
