Hearth is the Alvarez family's household budget site — seven working pages (dashboard, transactions, budgets, goals, bills, reports and planner) in plain static files that run entirely offline. November 2026 in place: $7,240 income, $4,505 spent, $1,200 auto-saved, $1,535 left to spend. Every control is live: add a transaction and the dashboard, budgets and reports move at once; switch months; adjust a budget limit; top up a savings goal; mark a bill paid; download the ledger as CSV; slide the 50/30/20 planner and watch the yearly savings change.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — desktop or phone, no network needed.
